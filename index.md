# Purpose
The African Genotype-to-Phenotype database (AG2P database) aims to provide comprehensive correlations between genotypes and phenotypes in African populations, using machine learning (ML) and deep learning (DL) tools. It integrates knowledge on African genetic variants, genes, diseases, and clinical, biological and other phenotypic data from diverse biomedical resources. It also provides genotype–phenotype correlations, including the clinical significance of African genetic variants. The AG2P database therefore supports both research and clinical genomics applications.
# Goals
- **Collect, curate and harmonise** genotype–phenotype associations identified in African individuals and cohorts.
- **Correlate** the collected African genotype and phenotype data using AI-based tools.
- **Design** and develop the African AG2P Database.
- **Enable** accurate clinical interpretation through harmonised, ancestry-aware annotations.
